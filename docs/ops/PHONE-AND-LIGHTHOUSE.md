# Prima: Lighthouse and phone check (about 40 minutes)

Words in bold are the words on the Prima screens. Write what you find in the tables. Send the tables to Claude: that is what Day 31 fixes are made from.

## Part 1: Lighthouse (10 minutes, on a computer)

1. Open the **test** version of Prima in Chrome.
2. Press F12 to open the developer tools. Choose the **Lighthouse** tab.
3. Choose Mode: Navigation, Device: Mobile. Tick Performance, Accessibility and Best practices. Press Analyze page load.
4. Do it three times: on the sign in screen (signed out), on **Home** after you sign in, and on the website at primahealth.com.ng.
5. Write the four numbers each time. Copy the name of every audit marked in red.

| Page             | Performance | Accessibility | Best practices | Audits in red |
| ---------------- | ----------- | ------------- | -------------- | ------------- |
| Sign in screen   |             |               |                |               |
| Home (signed in) |             |               |                |               |
| Website          |             |               |                |               |

What to aim for: Accessibility 95 or more, Best practices 95 or more, Performance 80 or more. Do not chase 100. A number below the aim is not a failure: the list of red audits is what matters.
